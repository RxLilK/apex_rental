# APEX RENTAL — Site vanilla HTML/CSS/JS

## Lancer le site

Aucune installation nécessaire. Double-clique sur `index.html`, ou clic droit >
"Ouvrir avec" > ton navigateur.

## Compte admin de démonstration

Un compte admin est créé automatiquement au premier chargement (dans
localStorage) :

- E-mail : `admin@apexrental.rp`
- Mot de passe : `admin123`

## ⚠️ Important

`localStorage` est utilisé uniquement pour simuler des comptes, réservations,
contrats et factures dans le cadre du jeu de rôle. Ce n'est PAS un système
sécurisé de production (les mots de passe sont stockés en clair dans le
navigateur).
